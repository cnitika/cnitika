## 🚀 Featured Project: Docker + CI/CD Practice

A hands-on project where I took a small app from my laptop to a production-style setup, step by step.

**What I built**
- App + PostgreSQL with Docker Compose (healthcheck, volume, data survives restarts)
- Backup script with `pg_dump` (timestamped, keeps the last 7) and a tested restore
- PostgreSQL moved out of Docker; the app connects to the external database
- Primary and replica with streaming replication (WAL), plus a failover test
- File sync with `rsync` and `cron`
- CI with GitHub Actions (install, build, test, coverage) and the same pipeline in Jenkins
- Docker image built in CI and pushed to GHCR, then deployed by pulling it
- Static site on Cloudflare to understand CDN caching
- Written notes on testing, high availability, and problems I faced

🔗 [View the project](https://github.com/cnitika/docker-cicd-practice)
